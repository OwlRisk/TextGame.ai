Architecture Overview
Four-layer architecture: a React frontend communicates via Next.js API routes that orchestrate multiple AI agents and persist state to PostgreSQL through Supabase — with real-time sync for multiplayer.
Frontend

Game room UI with streaming messages, multi-channel chat, player panels, and private boards. Three React context providers (Auth, Game, GameRoom) manage session, game list, and live room state with optimistic updates, localStorage persistence, and Supabase Realtime sync.

Key Features
From multi-agent AI to payment monetization, the platform covers a wide surface of modern full-stack product engineering.

Multi-Agent AI Orchestration

An AI Game Master dynamically coordinates multiple AI player agents. Each agent has unique personality traits, private knowledge, and strategic reasoning — creating emergent, unscripted gameplay.

14 Game Templates

Werewolf, Mafia, Avalon, Codenames, Spyfall, Escape Room, Trivia, Debate, 20 Questions, and more. Each has dedicated mechanics, role systems, and phase management via template drivers.

Real-Time Multiplayer

Supabase Realtime channels for game state sync, presence tracking, multi-channel chat, and TTS audio broadcast. Humans and AI players coexist in the same room with seamless turn-taking.

Voice Integration

Speech-to-text input (Whisper), text-to-speech output (Cartesia / Inworld) with per-player voice assignment. Room-level broadcast dedup ensures only one client pays for synthesis.

AI Avatar Generation

Dynamic avatar generation via DALL-E 3 or Replicate Flux with collision detection, multi-pass deduplication, gender-aware selection, and Supabase Storage caching with offset-based pool rotation.

Payment & Credits System

Stripe integration for one-time credit purchases and subscriptions. Model-aware token metering tracks usage per chat/image/TTS call with real-time balance enforcement and usage dashboard.

Guest & Sharing System

Two sharing paths: invite codes for multiplayer guest join (no account required, localStorage-based identity), and share tokens for read-only game previews. Guest sessions bypass auth with protected route detection.

Game Discovery

Browse and filter games by category (deduction, party, mystery, creative, brain) with featured highlights. Template presets drive the create flow. Discovery events feed into the analytics funnel.

Accessibility

Skip links, chat role="log" with aria-live, semantic ARIA labels across all interactive surfaces, viewport zoom support (scale up to 5x), and dedicated E2E a11y test coverage.

Engineering Depth
Technical Highlights
The non-obvious engineering decisions and architectural patterns that make this project interesting.

  • Hybrid Directive Protocol for AI Control

    The AI Host outputs natural language narration with embedded structured directives (ASSIGN_ROLE, ELIMINATE, NEXT_SPEAKER, GAME_OVER) and bracket blocks ([BOARD:...], [ACCESS:...], [SECTION:...]). This dual protocol maintains immersive storytelling while driving a deterministic game state machine — the parser extracts machine actions without breaking the narrative flow for players.

  • Three-Tier Prompt Architecture

    System prompts are separated into three composable layers: a shared GM base (gm-system-prompt), a runtime host layer with game-state-aware speaker/channel rules (host-prompt-builder), and per-AI-player prompts with personality, private knowledge, and role-specific reasoning (player-speak-prompt). Each tier has independent token limits, model selection, and context windows — preventing prompt bloat while maximizing relevance.

  • Template-Driven Game Mechanics

    Each game template injects specific mechanics via a driver module — phase ordering, voting resolution, role reveal rules, elimination logic. The host prompt is dynamically composed from base + template mechanics + progression policy, making it trivial to add new game types without touching the core engine. A single game-template-driver.ts file encodes the rules for all 14 games.

  • Distributed State with Three-Layer Persistence

    Game room state lives in three places: React context (optimistic UI), localStorage (offline / tab-crash recovery), and Supabase JSONB (source of truth for multiplayer). State merges handle concurrent guests, realtime echo dedup, and split-brain recovery with dedicated test coverage for edge cases like dual-tab and reconnect scenarios.

  • Cost-Aware TTS Broadcast Architecture

    Text-to-speech is synthesized by a single client (the room owner) and broadcast to all guests via a Supabase Realtime channel. This prevents N× cost duplication while maintaining synchronized audio. Voice assignment uses gender-aware, personality-matched selection from curated voice pools with per-player persistence.

  • Programmatic SEO at Scale

    100+ indexed pages generated from data-driven templates: 25 game landing pages with 4 JSON-LD schemas each (Game, FAQ, HowTo, Breadcrumb), 67 blog articles targeting competitor and long-tail keywords, dynamic sitemap generation, and a full conversion funnel tracked via GA4 from organic entry to checkout. Competitor keywords target Jackbox, Character.AI, AI Dungeon, Town of Salem, and more.
