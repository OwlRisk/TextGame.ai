# 玩家体验优化清单（Player-Facing）

从**玩家视角**梳理的可优化点，按优先级与实现成本分类。

---

## 一、已在本轮完成的改动

| 项目 | 说明 |
|------|------|
| **聊天空状态** | 无消息时显示「No messages yet」+ 简短引导（根据是否游戏中区分文案），避免空白一片 |
| **输入框提示** | Placeholder 增加「(Enter to send)」，减少不知道如何发送的情况 |
| **游戏房加载态** | 进入 `/game/[id]` 时若列表仍在加载，显示「Loading game…」而非直接「Game not found」；未找到时补充说明文案 |

---

## 二、建议优先做（小改动、收益高）

| 项目 | 说明 | 位置建议 |
|------|------|----------|
| **发送防连点** | 发送后 300–500ms 内禁用发送按钮或显示「发送中」，避免重复提交同一条 | `chat-area.tsx` `handleSend` |
| **分享成功反馈** | 点击分享后已有 toast，可考虑在分享按钮上短暂显示「已复制」或 tooltip | `channel-list.tsx` / 游戏页 `handleShare` |
| **规则/进度空状态** | Rules / Progress 无内容时显示「暂无规则」/「游戏开始后这里会显示进度」等 | `game/[gameId]/page.tsx` 中对应 ScrollArea |
| **Quick reply 加载中** | 快回复由 API 拉取，请求期间可显示骨架或「加载快捷回复…」避免误以为没有 | 游戏页 quickReplies effect + ChatArea 占位 |
| **当前发言者提示** | 轮到自己发言时已有「Wait for your turn」和 focus 高亮，可再强化一句「It’s your turn to speak」 | `chat-area.tsx` 已有，可微调文案 |

---

## 三、体验与可读性

| 项目 | 说明 |
|------|------|
| **键盘与焦点** | 聊天输入框、主要按钮保持可见 focus 环；确保 Tab 顺序合理（侧栏 → 频道 → 聊天 → 玩家列表） |
| **响应式 / 小屏** | 侧栏、频道列表、玩家面板在窄屏下可考虑折叠为抽屉或底部 Tab，避免聊天区被压得太窄 |
| **头像加载** | 头像生成中已有 fallback 与 loading，可统一骨架或占位图，减少布局跳动 |
| **错误重试** | Host 回复失败时已有 toast，可加「重试」按钮或自动重试一次（谨慎，避免刷 API） |

---

## 四、引导与首次体验

| 项目 | 说明 |
|------|------|
| **首次进入游戏房** | 可选：第一次进入某游戏时简短 tooltip（如「在这里发言，Host 会推进游戏」）可关闭且不再显示 |
| **规则/频道说明** | 在 Rules 或频道列表旁用一行小字说明「规则由 Game Master 设定」「不同房间对应不同讨论组」 |
| **Discover / My Games** | 未登录时 Discover 已有引导；My Games 空状态已有，可再强调「创建第一个游戏」的 CTA |

---

## 五、无障碍与稳定性

| 项目 | 说明 |
|------|------|
| **ARIA** | 聊天区域、私信折叠面板、玩家卡片（可点击查看资料）补充 `aria-label` / `role` |
| **Error Boundary** | 页面级 `error.tsx`、根 `global-error.tsx`，出错时友好提示而非白屏 |
| **网络/离线** | 请求失败时统一文案（如「网络异常，请稍后重试」），必要时区分 4xx/5xx |

---

## 六、后续可考虑（较大功能）

| 项目 | 说明 |
|------|------|
| **消息已读/送达** | 若有多端或多人，可显示「Host 已读」或「AI 正在输入」等（部分已有 typing） |
| **通知与提醒** | 轮到自己发言时浏览器通知（需权限）、或 Tab title 闪烁 |
| **游戏进度持久化** | 刷新或换设备后恢复进度与消息（依赖后端/同步方案） |
| **多语言** | 界面文案抽离为 i18n，便于后续中英等切换 |

---

建议下一步：**发送防连点** → **规则/进度空状态** → **Error Boundary**，再按需做键盘焦点与响应式。
