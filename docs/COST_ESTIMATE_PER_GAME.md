# 一局游戏成本估算（单局）

基于当前代码中的 API 调用与 **OpenAI 官方定价**（Standard 档）做的粗略估算。实际成本会随对话轮数、玩家数、是否用语音/头像等变化。

---

## 1. 涉及的 API 与模型

| 用途 | 接口/文件 | 模型/服务 | 说明 |
|------|-----------|-----------|------|
| GM 对话（流式） | `/api/chat/stream` | `OPENAI_CHAT_MODEL` 默认 `gpt-5.2` | 每轮用户+GM 各一次请求 |
| 快速回复建议 | `/api/suggest-gm-replies` | `gpt-4o-mini`，max_tokens 280 | GM 每条消息后可能调用 |
| 生成玩家 | `/api/generate-players` | `gpt-5.2` | 可能 2 次（决定人数 + 生成 JSON） |
| 生成主持人 | `/api/generate-host` | `gpt-5.2`，max_tokens 500 | 开局前 1 次 |
| 游戏图标 | `/api/generate-game-icon` | DALL·E 2，256×256 | 开局 1 张 |
| 玩家/主持人头像 | `/api/avatar` | 默认 `dalle-3`→ 实际用 **DALL·E 2** 256×256，或 Replicate (flux/sdxl) | 每角色 1 张 |
| 语音转文字 | `/api/transcribe` | Whisper | 按分钟计费，可选 |
| 游戏中 Host 发言 | `page.tsx` → `/api/chat/stream` | 同上 `OPENAI_CHAT_MODEL` | 每段 Host 发言 1 次 |
| 游戏中建议句 | `/api/suggest-prompts` | `gpt-4o-mini` | 可选、多次 |
| TTS（朗读） | 前端/语音服务 | 若用 OpenAI TTS：$15/1M 字符 | 可选 |

---

## 2. 定价参考（OpenAI Standard，约 2025）

- **gpt-5.2**：$1.75/1M input，$14/1M output  
- **gpt-4o-mini**：$0.15/1M input，$0.60/1M output  
- **DALL·E 2** 256×256：**$0.016/张**  
- **Whisper**：**$0.006/分钟**  
- **TTS**：$15/1M 字符（约 $0.015/千字）

*若在 .env 中把 `OPENAI_CHAT_MODEL` 改为 `gpt-4o-mini`，对话成本会明显下降。*

---

## 3. 典型一局假设

- **GM 阶段**：约 8 轮对话（用户发 8 条，GM 回 8 条）。  
- **开局**：7 名 AI 玩家 + 1 主持人 = 8 个头像，1 个游戏图标，1 次生成 Host，1 次生成玩家。  
- **游戏中**：约 15 段 Host 发言（开场、夜晚/白天、结算等）。  
- **语音**：按 2 分钟语音输入 + 少量 TTS 估算（可选）。

---

## 4. 单局成本估算（美元）

### 4.1 GM 对话阶段（gpt-5.2）

- 每轮约 4k input + 300 output tokens，8 轮 ≈ **32k input + 2.4k output**  
- 成本：32 × 1.75/1000 + 2.4 × 14/1000 ≈ **$0.056 + $0.034 ≈ $0.09**

### 4.2 快速回复（gpt-4o-mini）

- 8 次调用，每次约 500 in + 150 out → 4k in + 1.2k out  
- 成本：4 × 0.15/1000 + 1.2 × 0.60/1000 ≈ **$0.0014**

### 4.3 开局：生成玩家（gpt-5.2）

- 可能 2 次（决定人数 + 生成），合计约 6.5k in + 820 out  
- 成本：6.5 × 1.75/1000 + 0.82 × 14/1000 ≈ **$0.023**

### 4.4 开局：生成主持人（gpt-5.2）

- 约 1.5k in + 400 out  
- 成本：1.5 × 1.75/1000 + 0.4 × 14/1000 ≈ **$0.008**

### 4.5 游戏图标（DALL·E 2 256×256）

- 1 张：**$0.016**

### 4.6 头像（DALL·E 2 256×256，8 张）

- 8 × $0.016 = **$0.128**  
- *若用 Replicate (flux/sdxl)，需按 Replicate 定价另算。*

### 4.7 游戏中 Host 发言（gpt-5.2，约 15 段）

- 每段约 6k in + 150 out，15 段 ≈ 90k in + 2.25k out  
- 成本：90 × 1.75/1000 + 2.25 × 14/1000 ≈ **$0.1575 + $0.0315 ≈ $0.19**

### 4.8 游戏中建议句（gpt-4o-mini，约 5 次）

- 约 **$0.0015**

### 4.9 语音（可选）

- Whisper 2 分钟：2 × $0.006 = **$0.012**  
- TTS 约 2k 字符：**≈ $0.03**

## 6. 结论与浮动范围

- **不含语音**：一局约 **$0.35–0.50**（约 **¥2.5–3.5**，按 7 汇率粗算）。  
- **含少量语音**：再加约 **$0.04**，合计约 **$0.50**（约 **¥3.5**）。

主要变量：

1. **对话轮数**：GM 阶段轮数越多，成本越高。  
2. **`OPENAI_CHAT_MODEL`**：改为 `gpt-4o-mini` 可显著降低对话与 Host 发言成本（约可省一半以上）。  
3. **玩家数**：头像数 = 玩家数 + 1（主持人），每多 1 人约多 **$0.016**（DALL·E 2）。  
4. **头像模型**：用 Replicate 时需按其实时定价重算。  
5. **语音/TTS**：按实际使用分钟数和字符数线性增加。

建议在 OpenAI 控制台设置月度预算并关注 Usage 页面，以便按实际用量再微调估算。
