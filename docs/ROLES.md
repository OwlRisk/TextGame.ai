# 角色设计（4 种角色）

本系统包含 **4 种角色**，职责分离清晰：

---

## 1. Game Master（游戏大师）

- **职责**：帮助用户 **制定游戏规则**（规则设计阶段）。
- **场景**：与用户在聊天中对话，理解需求，编辑/完善规则（如狼人杀、谁是卧底、自定义规则等）。
- **实现**：Game Master 聊天界面（`GameMasterChat`），固定头像，与 Host 选型、游戏配置等联动。

---

## 2. Host（主持人）

- **职责**：**推进游戏**，包括：
  - 发布事件、阶段切换
  - 选择发言者、禁言
  - 修改用户属性表等游戏内管理
- **场景**：游戏进行中，主持流程、维持秩序、执行规则。
- **实现**：游戏内 `Player` 中 `isGameMaster: true` 的 AI 角色；身份来自 Host 选型（Echo、Nova 等）或按规则生成的 Host。UI 上标注为 **HOST**。

---

## 3. AI 玩家（AI Player）

- **职责**：**配合用户玩游戏**，按规则执行、发言、行动。
- **场景**：游戏进行中，与用户一起参与，遵循当前规则与角色设定。
- **实现**：`Player` 中 `isAI: true` 且 `isGameMaster: false`。可配置姓名、人格、背景等。

---

## 4. 用户（User）

- **职责**：**参与游戏**的真人玩家。
- **场景**：游戏进行中，以玩家身份发言、操作。
- **实现**：`Player` 中 `isAI: false`，UI 上通常显示为 **You**。

---

## 关系小结

| 角色         | 阶段       | 职责           | 标识 / 实现说明                          |
|--------------|------------|----------------|------------------------------------------|
| Game Master  | 规则设计   | 制定、编辑规则 | 聊天界面固定 GM 身份                     |
| Host         | 游戏进行中 | 推进游戏、控场 | `isGameMaster: true`，选型或生成 Host    |
| AI 玩家      | 游戏进行中 | 按规则游玩     | `isAI: true` 且非 Host                   |
| 用户         | 游戏进行中 | 参与游戏       | `isAI: false`，展示为 You                |

规则文案中，涉及 **阶段控制、发言、禁言、属性修改** 等，应表述为 **Host** 的职责，而非 Game Master。
